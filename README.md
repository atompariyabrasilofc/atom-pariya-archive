# Atom Pariya Archive — primeira versão

Este é o primeiro protótipo estático do site, preparado para personalização e publicação.

## Arquivos
- `index.html`: estrutura das páginas/seções.
- `styles.css`: identidade visual inicial preta, rosa e pêssego.
- `script.js`: menu mobile e interação visual dos filtros.

## Como visualizar
Abra `index.html` no navegador. Para publicar, envie os três arquivos para um repositório GitHub e importe o repositório na Vercel. Escolha um projeto estático/sem framework; não é necessário comando de build nem diretório de saída.

## Antes de publicar
1. Substituir o retrato ilustrativo e os símbolos pelos logos/fotos autorizados da fanbase.
2. Atualizar os links das contas oficiais e do canal correto do YouTube.
3. Inserir conteúdos reais nas seções e fichas de looks.
4. Rever datas, créditos, fontes e permissões de uso das imagens.
5. Manter claro que é um arquivo feito por fãs, sem afiliação oficial.

O protótipo não coleta dados de redes sociais automaticamente. A primeira versão foi pensada para receber conteúdo manualmente e crescer com uma base de dados posteriormente.
